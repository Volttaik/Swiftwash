# Swift wash — Modern E-Commerce Platform

A beautiful, modern e-commerce platform for household essentials and cleaning products, built with Next.js and Tailwind CSS.

## Features

✨ **Modern Design**
- Clean, professional interface with green theme
- Responsive design (mobile, tablet, desktop)
- Smooth animations and transitions

🛒 **Shopping Features**
- Product catalog with categories
- Real-time search and filtering
- Shopping cart with quantity management
- Wishlist functionality
- Product ratings and reviews

⚡ **Performance**
- Built with Next.js for fast performance
- Tailwind CSS for optimized styling
- Image optimization

## Tech Stack

- **Frontend**: Next.js 15 + React 19
- **Styling**: Tailwind CSS 4
- **Icons**: Lucide React
- **Language**: TypeScript

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Visit `http://localhost:3001` in your browser.

### Production Build

```bash
npm run build
npm run start
```
